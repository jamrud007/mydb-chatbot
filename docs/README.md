# Documentation & Samples

This directory contains generated documentation and sample outputs.

## Contents

### `/samples/`
Auto-generated sample files from the schema documentation generator:

- `schema_docs_sample.md` - Markdown schema documentation
- `schema_docs_sample.html` - HTML schema documentation (open in browser)
- `schema_docs_sample.json` - JSON schema documentation

### How to Generate

These files are auto-generated by running:

```bash
python tests/test_schema_docs.py
```

Or via API:
```bash
GET /api/schema/docs/markdown
GET /api/schema/docs/html
GET /api/schema/docs/json
```

## Viewing Documentation

### HTML (Recommended)
Open `samples/schema_docs_sample.html` in your browser for a beautiful, styled view of the database schema.

```bash
# Windows
start docs\samples\schema_docs_sample.html

# Linux/Mac
open docs/samples/schema_docs_sample.html
```

### Markdown
View `samples/schema_docs_sample.md` in any markdown viewer (GitHub, VS Code, etc.)

### JSON
For programmatic access, use `samples/schema_docs_sample.json`

## Features

The documentation includes:
- 📑 Table of Contents with anchors
- 📊 All tables and columns
- 🔑 Primary and foreign keys
- 📈 Optional row count statistics
- 🎨 Beautiful CSS styling (HTML)
