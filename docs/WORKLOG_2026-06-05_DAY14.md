## Identifikasi Masalah

### Gap kritis: MetricsCollector tidak menerima data

`MetricsCollector` dibangun lengkap di Day 17–18 dengan method `record_query_duration()`, `record_llm_call()`, dan `record_error()`. Endpoint `/api/metrics` sudah ada. Namun setelah ditelusuri dengan grep:

```
grep -r "record_query_duration\|record_llm_call\|record_error" --include="*.py"
```

Hasil: method-method tersebut **hanya dipanggil di test file** — tidak satupun dipanggil dari kode produksi. Artinya selama ini `/api/metrics` selalu mengembalikan semua angka 0. Metrics collector ada, tapi tidak ada yang memberi makan data ke dalamnya.

### Gap minor: `slow_query_count` tidak konsisten dengan window

`get_query_stats()` mengembalikan `slow_query_count: len(self.slow_queries)` — ini adalah hitungan all-time sejak server start, tidak difilter oleh `window_minutes`. Semua stats lain (avg, p95, p99) menggunakan window filter. Inkonsistensi ini membuat angka slow query tampak lebih besar dari kenyataan.

## Yang Dikerjakan

### 1. Wire `record_query_duration` + `record_error` ke `QueryExecutor` — `database/query_executor.py`

Tambah import `time` dan `get_metrics_collector`. Di method `execute()`:

- **Cache HIT path:** `record_query_duration(0, from_cache=True)` — 0 ms karena tidak menyentuh DB
- **Cache MISS path:** timing `_t0 = time.time()` sebelum `execute_query()`, lalu `record_query_duration(_duration_ms, from_cache=False)` setelah selesai
- **Exception path:** `record_error('SQL_EXECUTION_ERROR', user_id)`

Sekarang setiap query yang masuk — baik dari cache maupun eksekusi nyata — tercatat di MetricsCollector.

### 2. Wire `record_llm_call` ke `OpenAIClient` — `llm/openai_client.py`

Di `get_response()`, tambah timing `_t0 = time.time()` di awal setiap attempt loop:

- **Sukses:** `record_llm_call(_duration_ms, success=True)` setelah respons diterima
- **APIConnectionError / APITimeoutError:** `record_llm_call(_duration_ms, success=False)` sebelum retry
- **Exception lain:** `record_llm_call(_duration_ms, success=False)` sebelum raise

`OpenAIClient` dipakai oleh semua provider OpenAI-compatible (DeepSeek, OpenRouter, dsb.), jadi satu titik instrumentasi mencakup semua provider tersebut.

### 3. Fix `slow_query_count` window-filtered — `utils/metrics.py`

```python
# Sebelum:
'slow_query_count': len(self.slow_queries)  # all-time

# Sesudah:
cutoff = time.time() - self.window_seconds
slow_in_window = sum(
    1 for sq in self.slow_queries
    if sq.get('timestamp', '') >= datetime.fromtimestamp(cutoff).isoformat()
)
'slow_query_count': slow_in_window,           # dalam window
'slow_query_count_all_time': len(self.slow_queries)  # all-time tetap tersedia
```
